# Store with AI

مشروع متجر إلكتروني حديث مبني باستخدام Next.js 15 وTypeScript وTailwind CSS.

## Development

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## Status

تم إنشاء الهيكل الأساسي للمشروع على الفرع `main`. ستُضاف قاعدة البيانات، المصادقة، لوحة الإدارة، والميزات التجارية في المراحل التالية.
